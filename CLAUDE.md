# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run dev          # Start dev server (frontend + API routes) at localhost:3000
npm run build        # Production build — also runs TypeScript type checking and ESLint
npm run lint         # ESLint only
npm run audit:cards  # Template×CardData coverage gate — fails on any silently-dropped field
npm run predeploy    # audit:cards + build — run before every deploy
npx tsx --test scripts/tests/redirects.test.mts   # routing / redirect contract
```

Card-template invariant: every visual CardData field must render natively in a
template OR via UniversalBlocks (src/components/cards/UniversalBlocks.tsx),
gated by the audit-derived `*_NATIVE_KEYS` Sets in templates/v2/registry.ts.
`npm run audit:cards` enforces this — never hand-edit those Sets without
re-running it.

No separate backend process — Next.js API routes (`src/app/api/`) run within the same server.

Gates for marketing changes (v7): `npx tsc --noEmit -p .`, `npx next lint --dir src`, `npx tsx --test scripts/tests/redirects.test.mts scripts/tests/v7-routes.test.mts scripts/tests/menu-rules.test.mts scripts/tests/site-rules.test.mts scripts/tests/published-prices.test.mts scripts/tests/url-hygiene.test.mts scripts/tests/app-css.test.mts`, and the capture script `node scripts/site-capture.mjs <run> <paths…>` (needs `PLAYWRIGHT_CORE`, see the script header; writes `.shots/<run>/` with JPGs and `report.json`: HTTP status, console errors, horizontal overflow, axe violations; all must be clean at 1440 and 390 px). `npm run audit:headings` (with `BASE` set to a running `next start`) checks on 19 pages that no h1/h2 needs a mid-word break in de/en/tr; Archivo at `font-stretch: 116%` is wide, so long German words get a soft hyphen (`soft()` in `src/lib/soft-hyphen.ts` or `&shy;`). `npm run audit:stage` belongs to the retired v4 hero scene and no longer applies.

### Localization and routes

Public locales are `de`, `en`, `tr`. **Language follows the visitor's COUNTRY, never the browser language** (owner decision, #34/#35): locale-less **non-root** URLs (`/ki-beratung`, …) get a 307 by cookie (explicit choice) → upstream geo header (`x-vercel-ip-country`, `cf-ipcountry`, `x-country-code`, `x-geo-country`) → in-app `/api/geo` lookup over loopback (fail-open) → `ROUTING_DEFAULT_LOCALE` (`de`). TR → `tr`, DACH → `de`, everything else → `en` (`localeForCountry`). `Accept-Language` is not consulted. Detection never writes a cookie (only an explicit language switch does). Logic in `src/lib/locale-routing.ts` (pure, unit-tested), wiring in `src/middleware.ts`; `?geodebug=1` reflects the decision in an `x-opsolid-geo` header. `DEFAULT_LOCALE` (`en`) is for app surfaces only.

**Routes contract: `src/lib/v7-routes.ts`.** Page keys (`home, beratung, check, prozess, m365, agenten, anwendungen, schulungen, kompetenz, copilot, workflows, trainer, produkte, opso, opsoKarte, ueber, kontakt, blog, impressum, privacy`), `ROUTE` (German folder under `src/app/[locale]`) and `SLUG` (public slug per locale; EN and TR are localized, e.g. `/en/ai-automation-consulting/ai-check`, `/tr/yapay-zeka-danismanligi/yz-kontrolu`). Helpers: `href(key, locale, {hash, sub})`, `absUrl`, `alternates`, `publicToInternal`, `foreignSlugTarget`, `internalToPublic`, `keyForPublicPath`. Rules:

- Decision 73 (2026-11-15): the KI-Agenten course page `workflows` lives at `/ki-schulungen/ki-agenten` (EN `/ai-training/ai-agents`, TR `/yapay-zeka-egitimleri/yz-ajanlari`); the consulting page `agenten` moved to `/ki-beratung/ki-assistenten` (EN `/ai-automation-consulting/ai-assistants`, TR `/yapay-zeka-danismanligi/yz-asistanlari`), and `/ki-beratung/ki-agenten`, `/ai-automation-consulting/ai-agents` and `/products/kutasia` 301 to it in one hop. The Produkte page `produkte` lives at `/produkte` (EN `/our-products`, TR `/urunler`).
- The German home is served at `/` (200, `WebSite` markup). `/de` answers 308 to `/`. `/en` and `/tr` stay.
- An explicit language cookie (en/tr) gives a 307 from `/`; no geo redirect at `/`. Instead the middleware passes `x-opsolid-suggest` (`en`|`tr`) and the German home shows a dismissible language hint (never a redirect).
- The middleware rewrites a public EN/TR slug to its `ROUTE` folder and sets `x-public-path` (the URL the browser shows) next to `x-pathname` (internal). A path that belongs to another locale gets a 301 to the right slug.
- Retired URLs (old v4 pages, `/websites`, …) 301 in **one hop** to the public slug of the request locale (`src/lib/redirects.ts`); no chains, no loops. `www.opsolid.de` 301s to the apex.
- All internal marketing links use `href()` / an `Href` with `to`; never hand-write `/de/...`. Changing a slug needs a 301 and a test in `scripts/tests/`.
- Contact and privacy (decision 80, 2026-11-15): German slugs and route folders `/kontakt` and `/datenschutz`; EN keeps `/contact` and `/privacy`, TR `/iletisim` and `/privacy`. The old German URLs `/de/contact` and `/de/privacy` are EN slugs under `/de` and 301 in one hop through `foreignSlugTarget`; `/kontakt` is therefore not a retired key, and `/faq` and `/pricing` point at `/kontakt`. App pages that still hard-code `/contact` or `/privacy` (app footer, `FinalCTA`, `CustomRequestSection`, the card edit and manage pages) reach the page through that 301.

### Media and video

`MediaFigure` (with `VideoFigure`) is the one video slot. Rules:

1. Poster first: the `<picture>` poster is the first frame. Video sources are set only after `load` plus an idle callback, `preload="none"`, `muted playsInline loop`; portrait files for phones in portrait, landscape elsewhere, WebM before MP4. Reserve the aspect ratio (no layout shift).
2. A visible 44 px pause/play button (`aria-pressed`); the video also pauses off screen (IntersectionObserver) and in hidden tabs.
3. `prefers-reduced-motion` and the stored "Hintergrundvideo" choice (`opsolid-fx=off`, `FX_EVENT`, `src/components/v7/fx.ts`; the Werkstatt footer no longer shows the switch) keep the poster and fetch no video.
4. Captions are Etikett lines without "Abb. x.y" numbering: the kind ("Schema · …", "App-Screen · …", "Render · …") and the text, plus the "KI-generiert" chip (EN "AI-generated", TR "Yapay zekâ ile üretildi") when the media is AI-made (`ai`).

6. Self-hosted only: images and video come from `/public`, fonts via `next/font/local`; no remote images, scripts, iframes, embeds or analytics at run time. Screenshots use `components/v7/Img` (not `next/image`) and the browser/phone frames in `components/v7/frames` (vendored Magic UI, MIT). Real proof only; never another user's data.
